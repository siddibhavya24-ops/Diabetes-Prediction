# 🩺 Diabetes Prediction using Machine Learning

## 📌 Project Overview
This project predicts whether a person is diabetic or non-diabetic using Machine Learning. The model is trained on the Pima Indians Diabetes Dataset and deployed using Streamlit.

## 🚀 Features
- Predicts diabetes based on patient health data.
- User-friendly Streamlit web application.
- Trained using Logistic Regression.
- Simple and interactive interface.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

## 📊 Input Features
- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age

## 🎯 Output
- Diabetic
- Non-Diabetic
